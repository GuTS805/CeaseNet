# Code of Conduct

Everyone who takes part in CeaseNet, in issues, pull requests or anywhere else the project meets, is expected to:

- be respectful, whatever someone's language, background or level of experience
- write plainly, so that people reading in a second language can follow
- never post anyone's personal details, or a key that isn't theirs, without their consent
- disagree about ideas, not people

Harassment, threats, slurs and doxxing are not tolerated. Maintainers may remove content and block people who break these rules.

To report a problem, contact the maintainers privately through a [GitHub security advisory](https://github.com/GuTS805/CeaseNet/security/advisories/new). Reports are kept confidential.

This code is adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org).
